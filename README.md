# Media Converter

Aplikacja webowa do transkodowania plików multimedialnych (wideo/audio).

## Stack

- Backend: Django 5 + DRF
- Frontend: React 18 + Vite 5 + Tailwind
- Kolejka: Celery + Redis
- DB: PostgreSQL 16

## Wymagania

- Python 3.11+
- Node 18+
- Docker + Docker Compose

## Uruchomienie

```bash
cp .env.example .env
docker compose up
```
